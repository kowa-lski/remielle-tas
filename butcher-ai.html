Dead End Butcher: enemy AI

The Behavior Designer trees the client runs for Cottus (Dead End Butcher), decoded from the CN Beta 3.3.2 client. Each designer note is translated, and hovering a row shows the original Chinese. CALL chips open the sub-tree a node runs.

    How the Butcher decides

    1. Root reads the animator phase (Int_CurrentPhase), loads that phase's default numbers, and runs Phase 1 or Phase 2.
    2. A phase tree is one big Parallel of always-running branches: target selection, cooldowns, timers, attack counters, weight bookkeeping, and the reactive defence and pursuit branches.
    3. Action choice fires when Bool_ActionReady is set. The mode is leisurely (0) or pressing (1) (Int_ActionMode).
    4. Roll 1, attack or stand-off: weighted by Coefficient_01 (attack; P1 100, +20 per step) against Coefficient_02 (stand-off; P1 50, +10), at P1 #898 (leisurely) and #1080 (pressing). The note on #898 was copied from the skill picker, but its weights are these two coefficients. After each attack, P1 rate raises stand-off by the caller's Float_AddCoefficient (50 or 100) if the attack hit, and lowers it on a miss or a parry. It then rolls a short, medium or long stand-off, which sets AttackCD to a random 3–4, 4–6 or 6–6.5 s.
    5. Roll 2, which skill: a weighted pick of skills 1–9 using Weight_0X_Real. Each step, the condition check copies _Current into _Real only for skills whose distance and angle gates pass. Weights grow after every attack and once a second while standing off, and they reset every 60 s.
    6. Pursuit runs follow-ups keyed on the current animation (IsName P1_Attack_05 …). Those follow-ups make small fixed-odds rolls, such as 50/50 for a fast or slow slam.
    7. Every random task uses useSeed = 0, so all rolls come from Unity's shared UnityEngine.Random stream.
